# Altıntaş Mobilya — kurulum ve güncellemeler

Bu depo yalnızca Altıntaş Mobilya Yönetim Sistemi'nin Windows ve Mac kurulum dosyalarını barındırır.
Kaynak kod ve veriler burada değildir.

- **İlk kurulum:** [Sürümler](../../releases/latest) sayfasından `Altintas-Mobilya-Kurulum-*.exe` dosyasını indirip çalıştırın.
- **Mac:** `Altintas-Mobilya-Mac-*.zip` dosyasını indirip açın, uygulamayı Uygulamalar klasörüne taşıyın.
- **Güncelleme:** Program yeni sürümü kendisi bulur, arka planda indirir ve "Şimdi güncelle" onayınızla kurar ("Daha sonra" derseniz program kapanırken kurulur). Kurulumdan sonraki ilk açılışta veriler yedeklenir. Mac'te de güncelleme program içinden kurulur (1.12.0 ve sonrası).
