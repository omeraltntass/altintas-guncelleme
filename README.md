# Altıntaş Mobilya — kurulum ve güncellemeler

Bu depo yalnızca Altıntaş Mobilya Yönetim Sistemi'nin Windows kurulum dosyalarını barındırır.
Kaynak kod ve veriler burada değildir.

- **İlk kurulum:** [Sürümler](../../releases/latest) sayfasından `Altintas-Mobilya-Kurulum-*.exe` dosyasını indirip çalıştırın.
- **Güncelleme:** Program yeni sürümü kendisi bulur ve "Güncelle" onayınızla kurar; kurulumdan önce veriler yedeklenir.
